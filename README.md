# Nanozyme-ROS

This repository contains the curated dataset used for the study of nanozyme-mediated reactive oxygen species (ROS) homeostasis in crops.

## Dataset

The dataset was compiled from peer-reviewed literature and contains experimental records describing crop responses to metal oxide nanomaterials/nanozymes under different exposure conditions.

Main dataset file:

- `crop_nanozyme_ros_dataset_v1.0.xlsx`

The dataset includes 1,329 curated experimental records from 57 studies. Variables include plant species, exposure target, exposure medium, experimental environment, concentration class, plant life stage, nanoparticle type, endpoint information, material properties, and response values.

## File Description

| File | Description |
|---|---|
| `crop_nanozyme_ros_dataset_v1.0.xlsx` | Curated dataset used for model development, analysis, and nanozyme screening |

## Usage

This dataset can be used to reproduce the data analysis, machine learning modelling, and nanozyme screening workflow described in the associated manuscript.
